# 📊 Analysis of Investment Information Sources

## 📌 Project Overview

The **Analysis of Investment Information Sources** project is a Power BI dashboard designed to analyze the various sources investors use to gather investment-related information. The dashboard presents interactive visualizations and insights to understand investor preferences, information channels, and decision-making patterns.

---

## 🎯 Objectives

* Analyze different sources of investment information.
* Visualize investor preferences using interactive dashboards.
* Identify trends and patterns in information usage.
* Generate meaningful insights from financial data.
* Support data-driven decision-making through business intelligence.

---

## 🛠️ Technologies Used

* Microsoft Power BI
* Data Analysis
* Data Visualization
* Business Intelligence
